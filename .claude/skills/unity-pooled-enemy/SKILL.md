# 풀링 오브젝트 작성 규칙

- `ObjectPoolManager`는 보관/활성화만 한다. 상태 초기화는 하지 않는다.
- **꺼낼 때**: 스포너(예: `MonsterSpawner`)가 `GetObject` 직후 `Init(...)`을 호출해 체력·색상·타겟·코루틴 등 **모든 가변 상태**를 초기값으로 되돌린다.
- **반납할 때**: 반납하는 쪽이 `ReturnObject` 전에 정리 메서드(`OnDespawn`)를 호출해 이벤트 구독 해제, 코루틴 중지, 임시 색상/효과 복원을 한다.
- 새 필드를 추가하면 `Init`(초기화)과 `OnDespawn`(정리) **둘 다**에 처리 여부를 적는다.
- 보스처럼 상태가 많은 대상은 `OnDespawned`가 실제로 호출되는 경로가 있는지 호출 지점을 grep으로 확인한다.
- `Update`에서 할당을 만들지 않는다. 컴포넌트 참조는 `Awake`에서 캐시한다.
- AI는 Unity를 실행할 수 없다. 완료 보고에 "실행 확인 안 됨"과 사람이 눈으로 확인할 시나리오(예: 같은 몬스터를 10번 반복 스폰/처치)를 적는다.
